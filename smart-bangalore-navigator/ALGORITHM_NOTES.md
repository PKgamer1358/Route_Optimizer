# Academic DSA Mapping

| Feature | Data Structure | Algorithm | Complexity |
|---|---|---|---|
| Graph storage | Adjacency List (JS object) | — | O(V + E) space |
| Shortest distance | Min-heap (priority queue) | Dijkstra | O((V+E) log V) |
| Fastest path | Heuristic priority queue | A* | O((V+E) log V) |
| Min-traffic path | Queue (FIFO) | BFS | O(V + E) |
| Route recalculation | Graph edge reweighting | — | O(E) |
| Nearest location search | Brute-force coord scan | Haversine formula | O(V) |
| Route history | Array (LIFO display) | — | O(1) insert |
